# SimClock-CYD
A colleague recently lamented not having a clock in the nursing simulation lab that she could control directly to display simulated time during simulation scenarios. I couldn't find any existing products or projects that fit our need, so in my free time, I decided to have a go at building my own solution using the ESP32-2432S028R, aka Cheap Yellow Display (CYD), since I already had one on hand.
You'll need a CYD that's been flashed with MicroPython for this project. Simply place ili9341.py, index.html, main.py, script.js, and style.css in the root directory of the CYD running MicroPython and restart the CYD. The CYD creates its own WiFi network with the SSID "SimClock" and password "simulation". I recommend using your phone to connect to this network during simulation labs. When you join the network, you should be redirected to a captive portal with the main control panel. If you aren't automatically redirected to the control panel, enter 10.0.0.1 in your address bar.
The user interface is pretty straightforward with select boxes for the hours, minutes, and AM/PM, a date picker for the date, and a set button to send the selected date and time to the SimClock CYD. I added a fast-forward button to skip ahead in 5-minute increments for good measure.
